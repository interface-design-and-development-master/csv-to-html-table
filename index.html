About:

This is a small tool I built for RMIT Digital Design's Interface Design and Development specialisation.

As part of the assignments you'll need to display your git commit history on your specialisation work index page. Getting the information is pretty easy, you just need to run the following command in a terminal opened in your git repository's folder: 

git log --pretty=format:"%an,%ad,%s,%b" > commit_history.csv

In WebStorm I can right-click on my folder in the project pane, go to open in and then select terminal.

In VS Code I can go to my view menu and then select terminal.

Running the command will create a new file in your folder called "commit_history.csv" which you can upload here to convert it to HTML.

You'll be able to preview the table here before downloading it as a text file, but note that the preview has some CSS applied. You can download the CSS I've used for reference here:
